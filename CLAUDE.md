# Lectio

FastAPI service that takes the text of a scientific paper and returns a structured summary generated by an LLM and validated with Pydantic. Deployed on Cloud Run with Secret Manager and Cloud Deploy.

## Working rules
* Small steps, one file or one concept at a time. Explain the plan briefly and wait for approval before writing code.
* gcloud commands and anything that creates cloud resources or costs money are run by the user, never by you.
* Never read or print .env files or secrets. Never commit secrets.
* Never push without approval.
* When something fails, show only the relevant lines of the error.

## Language
* Everything committed to the repo is in English. Code, comments, docstrings, README, docs and commit messages.
* Comments explain why, not what, and stay short. Long explanations belong in the conversation, not in the code.
* Commit messages follow Conventional Commits.

## Context files (read only when needed)
* `docs/ROADMAP.md` phases and current status. At the start of a session read only the Current status section.
* `docs/ARCHITECTURE.md` current architecture and how it would scale.
* `docs/DECISIONS.md` decisions with rationale and trade offs.

## Stack
Python 3.12, FastAPI, Pydantic v2, pydantic settings, Anthropic SDK (model set by LLM_MODEL), pytest, ruff, strict mypy, Docker. GCP in us-central1 with Artifact Registry, Cloud Build, Cloud Run, Secret Manager and Cloud Deploy. GitHub Actions.

## Layout
* backend/app API code
* backend/tests tests
* deploy Skaffold and Cloud Deploy files
* docs documentation

## Commands (from backend, with .venv active)
* uvicorn app.main:app --reload --port 8080
* pytest -q
* ruff check . and ruff format --check .
* mypy app tests

## Conventions
* Type hints everywhere, strict mypy with no errors.
* Separate input and output models in app/schemas.py.
* Dependencies declared with Annotated and Depends.
* The LLM is never called for real in tests. Use dependency_overrides or a fake.
* An invalid LLM answer maps to 502, an unavailable provider maps to 503.
* At the end of each step update Current status in the ROADMAP, and DECISIONS when a new decision is made.
